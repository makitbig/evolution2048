Privacy Policy

Blucos Uploader · Effective November 14, 2026

The short version

  • Blucos Uploader is an internal tool. Its only user is Blucos, and the only Google account it signs in to is our own YouTube channel's.
  • It uses the YouTube API Services only to upload our own videos to that channel and to read the channel's name.
  • It collects no data about any other person, has no server, and shares nothing with third parties.

1. YouTube API Services

Blucos Uploader uses the YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

2. What the tool accesses

After our channel owner signs in with Google OAuth 2.0, the tool requests two scopes:

  • youtube.upload — to upload our own videos, with the title, description and tags we write.
  • youtube.readonly — only to read our own channel's name once, to confirm that it signed in to the right channel.

It does not access other users' channels, comments, subscribers, analytics or any other YouTube data.

3. What is stored, and where

  • OAuth token. The access and refresh token for our channel is saved in one file on our own computer, readable only by our user account. It is never uploaded anywhere else.
  • Upload log. After each upload the tool writes the date and the resulting video link to a local log file.
  • No API data is sent to any server we run (we have none), sold, or shared with anyone.

4. Deleting data and revoking access

Access can be revoked at any time from the Google Account security settings page: https://myaccount.google.com/permissions. When access is revoked, or when we stop using the tool, we delete the token file and the local log from our computer. Stored data is kept no longer than 30 days after access ends. You can also ask us to delete anything by emailing the address below; we will do it within 7 days.

5. Cookies and tracking

The tool is a command-line script. It does not use cookies, device identifiers, analytics or advertising.

6. Changes and contact

We will post any changes on this page and update the date above.
